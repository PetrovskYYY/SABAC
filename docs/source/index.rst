Overview
--------

SABAC (Simple Attribute Based Access Control) is a Python implementation of ABAC
based on the XACML 3.0 model.

Features
--------
- Full ABAC stack: PDP, PAP, PEP, PIP
- XACML 3.0 combining algorithms
- Async evaluation for non-ordered algorithms
- JSON-based policy definition
